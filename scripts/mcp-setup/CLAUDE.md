# Références pour sites 3D et animés

Quand je demande un site web animé, scroll-driven ou 3D, inspire-toi de ces ressources avant de proposer un design. Ce sont des références visuelles et des bibliothèques de composants, pas des serveurs MCP. Vérifie la licence avant de réutiliser du code.

## Inspiration

- [scrolltide.co](https://scrolltide.co) : plus de 600 invites primées avec code source complet pour des sites 3D et à défilement animé. À copier dans Claude, Cursor ou Lovable, puis à modifier.
- [awwwards.com](https://www.awwwards.com) : les sites qui ont vraiment gagné.
- [godly.website](https://godly.website) : sites soigneusement sélectionnés, avec un vrai savoir-faire.
- [60fps.design](https://60fps.design) : animations d'interface bien réalisées.

## Composants

- [21st.dev](https://21st.dev) : composants copy-paste de la communauté.
- [ui.aceternity.com](https://ui.aceternity.com) : composants animés à fort impact visuel.
- [magicui.design](https://magicui.design) : composants animés pour les pages d'atterrissage.

## Moteurs et expériences

- [threejs.org](https://threejs.org) : le moteur derrière la plupart des 3D sur le web.
- [shadertoy.com](https://www.shadertoy.com) : expériences avec des shaders.

## Génération

- [lovable.dev](https://lovable.dev) : de l'idée à l'app fonctionnelle.

## Façon de travailler

- Stack par défaut : Next.js, Tailwind, Framer Motion ou GSAP, Three.js, Lenis pour le scroll.
- Propose deux ou trois directions visuelles avant de coder.
- Cite la référence utilisée et son origine quand tu t'en inspires.
- Ne copie pas un composant ou un site à l'identique : adapte-le à ma marque.

## Vidéo programmatique

- **Remotion** : le MCP est déprécié. Installe les skills dans le projet Remotion avec `npx remotion skills add`, puis utilise `/remotion-docs` pour la documentation à jour.
- **HyperFrames** (HTML/CSS/JS vers MP4, Apache-2.0) : plugin `hyperframes@hyperframes` ; CLI `npx hyperframes init|preview|render`.
- **Montage** : Kinocut (`kino`), skill `beat-sync-video-editing` pour caler les coupes sur la musique.
